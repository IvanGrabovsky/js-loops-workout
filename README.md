## 📚 Програма тренажера (7 модулів)

1. **Модуль 1: Цикл while та поняття ітерації (25 завдань)**
   - Що таке цикл, необхідність повторень, синтаксис `while`, поняття ітерації, лічильника і кроку.
2. **Модуль 2: Цикл do...while (25 завдань)**
   - Цикл з післяумовою, гарантоване перше виконання, валідація введення, повторні спроби.
3. **Модуль 3: Параметричний цикл for (30 завдань)**
   - Секції ініціалізації, умови та кроку; ітерація по діапазонах, робота з рядками та масивами.
4. **Модуль 4: Оператори break, continue та захист від вічних циклів (25 завдань)**
   - Дострокове переривання `break`, пропуск ітерації `continue`, небезпека вічних циклів, Watchdog-запобіжники.
5. **Модуль 5: Позначення циклів у блок-схемах (20 завдань)**
   - Блок підготовки (шестикутник), ромб умови (передумова/післяумова), прямокутник дії, стрілка зворотного звʼязку (loopback).
6. **Модуль 6: Вкладені цикли та матриці (25 завдань)**
   - Двовимірні масиви, сітки, таблиці множення, комбінації, сортування бульбашкою, обхід по спіралі.
7. **Модуль 7: Робота з відлагоджувачем (Debugger & DevTools) (15 завдань)**
   - Що таке відлагоджувач, цілі та завдання, інструкція `debugger;`, покрокове виконання (Step into, Step over, Step out, Resume), вікна Scopes, Watch, Call Stack, Memory, точки зупинки (breakpoints) та виправлення типових багів.

## 🛠️ Локальний запуск та тестування через Vitest

### 1. Клонування репозиторію
```bash
git clone https://github.com/IvanGrabovsky/js-loops-workout.git
cd js-loops-workout
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Запуск веб-тренажера локально
```bash
npm run dev
```
Відкрийте у браузері: `http://localhost:5173`

### 4. Запуск автоматичних тестів у терміналі (Vitest)
```bash
npm test
```
Або в режимі постійного спостереження (watch):
```bash
npm run test:watch
```
