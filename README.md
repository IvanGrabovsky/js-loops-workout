## 📚 Програма воркаута (7 модулів, 165 завдань)

1. **Модуль 1: Цикл while та поняття ітерації (25 завдань)**
   - Синтаксис `while`, поняття ітерації, лічильника і кроку, накопичення суми та добутку.
2. **Модуль 2: Цикл do...while (25 завдань)**
   - Цикл із гарантованим першим виконанням (післяумова), валідація введення, генератори випадкових чисел до збігу.
3. **Модуль 3: Параметричний цикл for (30 завдань)**
   - Секції ініціалізації, умови та кроку; ітерація по числових діапазонах, робота з рядками та масивами.
4. **Модуль 4: Оператори break, continue та захист від вічних циклів (25 завдань)**
   - Достроковий вихід `break`, пропуск ітерації `continue`, небезпека вічних циклів та Watchdog-запобіжники.
5. **Модуль 5: Позначення циклів у блок-схемах (20 завдань)**
   - Блок підготовки (шестикутник), ромб перевірки умови (передумова/післяумова), зворотна стрілка (loopback).
6. **Модуль 6: Вкладені цикли та матриці (25 завдань)**
   - Двовимірні координатні сітки, таблиці множення, сортування бульбашкою, пошук екстремумів у матрицях.
7. **Модуль 7: Робота з відлагоджувачем (Debugger & DevTools) (15 завдань)**
   - Інструкція `debugger;`, покрокове виконання (Step into, Step over, Step out, Resume), робота з панелями Scopes, Watch, Call Stack, виправлення типових багів.

### Крок 6. Написання коду завдань у `src/`
Усі файли для вирішення знаходяться у папці `src/`:
- `src/01-while-basics.js` — Завдання 1.1 ... 1.25
- `src/02-do-while.js` — Завдання 2.1 ... 2.25
- `src/03-for-loops.js` — Завдання 3.1 ... 3.30
- `src/04-break-continue.js` — Завдання 4.1 ... 4.25
- `src/05-flowcharts.js` — Завдання 5.1 ... 5.20
- `src/06-nested-loops.js` — Завдання 6.1 ... 6.25
- `src/07-debugger-hunting.js` — Завдання 7.1 ... 7.15

Відкрийте відповідний файл у VS Code. Кожне завдання оформлене як експортована функція.  
Приклад вирішення:
```javascript
// Завдання 1.1: Підсумувати числа від 1 до N за допомогою while
export function sumToN(n) {
  let sum = 0;
  let i = 1;
  while (i <= n) {
    sum += i;
    i++;
  }
  return sum;
}
```

> **Важливо**: Завжди зберігайте ключове слово `export function` перед назвою функції, інакше автотести не зможуть її імпортувати!

### Крок 7. Запуск автоматичних тестів (Vitest)
Перевіряти правильність написаного коду можна кількома способами:

1. **Запуск усіх тестів однією командою**:
   ```bash
   npm test
   ```
2. **Режим автоматичного спостереження (watch mode)** — тести перезапускаються щоразу при збереженні файлу:
   ```bash
   npm run test:watch
   ```
3. **Запуск тестів лише для одного модуля**:
   ```bash
   npx vitest run test/01-while-basics.test.js
   ```
4. **Перевірка у веб-тренажері**:
   - Натисніть **Ctrl + Enter** або кнопку **«Запустити тести»**.
   - Щоб відформатувати код за стандартом, натисніть **Shift + Alt + F** або кнопку **«Форматувати Prettier»**.

### Крок 9. Створення Pull Request (Здача домашнього завдання)
1. Відкрийте сторінку **вашого форку** на GitHub (`https://github.com/<ВАШ_НІКНЕЙМ>/js-loops-workout`).
2. Вгорі зʼявиться банер із кнопкою **«Contribute»** ➔ оберіть **«Open pull request»**.
