Модуль 4. Цикли, використання відлагоджувача

Повний фундаментальний конспект: від модальних вікон взаємодії з користувачем (alert, prompt, confirm) до всіх різновидів циклів, блок-схем за стандартом та професійного володіння Chrome DevTools Debugger.

Блок 1 · Взаємодія з браузером

1. Взаємодія з користувачем: alert, prompt та confirm

У браузерному середовищі JavaScript має три вбудовані функції для швидкого спілкування з користувачем: alert, prompt та confirm. Усі вони створюють модальні вікна (modal windows).

Що означає «модальне вікно»?
Коли зʼявляється таке вікно, виконання JavaScript-коду тимчасово зупиняється (фризиться), а користувач не може взаємодіяти з рештою сторінки (клікати по кнопках, виділяти текст, скролити), доки не натисне кнопку підтвердження чи закриття. Розташування та дизайн цих вікон строго контролюються браузером і операційною системою — змінити їхній вигляд через CSS неможливо.

💬 alert(message) — Сповіщення

Показує спливаюче вікно з переданим повідомленням і єдиною кнопкою «OK».
• Повертає: завжди undefined.
• Призначення: інформування про подію чи завершення обчислень.

alert("Вітаємо у світі циклів JavaScript!");

✏️ prompt(title, [default]) — Введення даних

Показує вікно з текстовим полем вводу та двома кнопками: «OK» і «Скасувати» («Cancel»).
• Повертає: введений рядок (string) при «OK» або null при «Скасувати» чи натисканні Esc.
• default: необов'язкове початкове значення в полі вводу.

let userName = prompt("Як вас звати?", "Гість");

❓ confirm(question) — Підтвердження

Ставить запитання з варіантом вибору з двох кнопок: «OK» і «Скасувати».
• Повертає: true при «OK», false при «Скасувати» чи Esc.
• Призначення: захист від небезпечних дій (видалення, скидання, підтвердження замовлення).

let isBoss = confirm("Ви справді готові до тестів?");

🏋️‍♂️ Практичні завдання з alert, prompt, confirm (Спробуйте самі!)

Виконайте завдання прямо зараз у консолі браузера або натиснувши інтерактивні кнопки:

Завдання 1.1: Знайомство та перевірка на null

Запитайте в користувача його імʼя через prompt. Якщо користувач натиснув «Скасувати» (значення null), виведіть «Дію скасовано!». Якщо ввів імʼя — привітайте його: «Привіт, [імʼя]!».

Показати еталонний код розвʼязку
let name = prompt("Як вас звати?", ""); if (name === null) { alert("Дію скасовано!"); } else if (name.trim() === "") { alert("Ви не ввели жодної літери!"); } else { alert("Привіт, " + name + "!"); }
Завдання 1.2: Калькулятор суми без конкатенації

Запитайте у користувача два числа по черзі через prompt. Додайте їх математично (використавши унарний плюс + або Number()) та виведіть суму через alert.

Показати еталонний код розвʼязку
let a = prompt("Перше число:", "10"); let b = prompt("Друге число:", "20"); let sum = +a + +b; // або Number(a) + Number(b) alert("Сума чисел дорівнює: " + sum);
Завдання 1.3: Захист операції через confirm

Запитайте підтвердження: «Бажаєте запустити цикл від 1 до 5?». Якщо користувач натиснув «OK», виконайте цикл і покажіть результат. Якщо «Скасувати» — виведіть повідомлення про зупинку.

Блок 2 · 0 Цикли (Loops)

0. Цикли: Фундамент повторюваних алгоритмів

• Що таке цикл?

Цикл (Loop) — це фундаментальна синтаксична конструкція мови програмування, яка забезпечує багаторазове повторення певної послідовності інструкцій (тіла циклу) доти, доки істинна (true) задана логічна умова.

• Необхідність використання циклів. Приклади використання

Без циклів програмування перетворилося б на нескінченний копіпаст рядків коду (порушення ключового інженерного принципу DRY — Don't Repeat Yourself). Якщо вам треба вивести числа від 1 до 1000 або надіслати email 50 000 користувачів, писати 50 000 однакових команд неможливо.

Приклади бойового застосування циклів у реальних проектах:

  • 🛒 E-commerce: перебір товарів у кошику клієнта для розрахунку загальної суми зі знижками.
  • 💬 Чати та стрічки новин: рендеринг списку повідомлень, отриманих з сервера (WebSocket).
  • 🎮 Game Development: ігровий цикл (Game Loop), що виконується 60 разів на секунду для оновлення координат і рендерингу кадрів.
  • 🔄 Long Polling / Retry: повторне відправлення мережевого запиту у разі збою з затримкою до 3 спроб.
  • 📊 Аналітика даних: фільтрація масивів, агрегація показників виручки, пошук екстремумів (min/max).

• Цикл while (з передумовою)

Синтаксис циклу while:

while (умова) { // тіло циклу (виконується, поки умова повертає true) }

Цикл називається циклом з передумовою, оскільки умова обчислюється ДО виконання тіла циклу. Якщо умова хибна з самого початку (false), тіло циклу не виконається жодного разу.

let count = 3; while (count > 0) { console.log("Відлік: " + count); count--; // декремент: зменшуємо змінну на 1 } // Результат у консолі: // Відлік: 3 // Відлік: 2 // Відлік: 1

• Поняття ітерації

Ітерація (Iteration) — це один одиничний повний прохід тіла циклу. Змінна, яка відстежує номер поточної ітерації і змінюється на кожному кроці, називається лічильником циклу (loop counter, зазвичай позначається літерами i, j, k від англійського index / iterator).

Таблиця трасування стану пам'яті для let i = 0; while (i < 3) { i++; }:

Ітерація Значення i на вході Перевірка умови i < 3 Дія в тілі циклу Значення i після ітерації
Початок 0 0 < 3 → true (входимо) i++ 1
1-а ітерація 1 1 < 3 → true (входимо) i++ 2
2-а ітерація 2 2 < 3 → true (входимо) i++ 3
Перевірка виходу 3 3 < 3 → false (вихід!) — 3 (цикл завершено)

• Позначення циклів у блок-схемах. Блок циклу

У класичному інженерному моделюванні алгоритмів (стандарт ISO 5807 / ГОСТ 19.701) цикли зображуються комбінацією стандартних геометричних фігур:

🔷 Ромб (Decision)

Перевірка умови продовження циклу. Має два виходи: гілка «ТАК / YES» (перехід до тіла) та гілка «НІ / NO» (вихід із циклу).

🛑 Шестикутник (Preparation)

Спеціальний блок підготовки для параметричного циклу for. Вказує початкове значення, граничне значення та крок: i = 1, 10, 1.

↩️ Лінія петлі (Loopback)

Зворотна стрілка, яка спрямовує потік виконання від нижнього краю тіла циклу назад на вхід перевірки умови.

• Приклади побудови програм з використанням циклів мовою блок-схем

Нижче наведено інтерактивну SVG-діаграму алгоритму циклу while. Зверніть увагу на червону пунктирну лінію — це зворотний звʼязок (Loopback), що повторює кроки:

• Оператори break i continue у циклах

Зазвичай цикл завершується, коли його умова стає хибною. Проте ми можемо примусово втрутитися в хід виконання за допомогою двох операторів:

🛑 break — Повний аварійний вихід

Миттєво припиняє виконання всього циклу і передає керування на рядок одразу після фігурної дужки циклу.

let sum = 0; while (true) { let val = +prompt("Введіть число (0 для зупинки):", "0"); if (!val) break; // Вихід при введенні 0 sum += val; } alert("Сума: " + sum);

⏭️ continue — Пропуск поточної ітерації

Не зупиняє весь цикл, а лише достроково завершує поточну ітерацію й одразу переходить до перевірки умови наступної.

for (let i = 0; i < 10; i++) { // Якщо число парне, пропускаємо його if (i % 2 === 0) continue; console.log(i); // Виведе 1, 3, 5, 7, 9 }
Мітки для break/continue (Labels):
Що робити, коли треба вийти одразу з двох чи трьох вкладених циклів? Звичайний break зупинить лише внутрішній цикл. Для виходу з зовнішнього циклу використовують мітку (label):
outerLoop: for (let i = 0; i < 3; i++) { for (let j = 0; j < 3; j++) { let input = prompt(`Координати (${i}, ${j}). Введіть 'stop' для виходу:`, ""); if (input === 'stop') break outerLoop; // Розриває ОБИДВА цикли! } } alert("Завершено!");

• Вічний цикл (Infinite Loop)

Вічний цикл — це критична помилка в коді, коли логічна умова циклу ніколи не стає false.

Головні причини виникнення вічних циклів:

  1. Забули написати крок інкременту/декременту лічильника (наприклад, пропустили i++ всередині while).
  2. Лічильник змінюється не в той бік (наприклад, let i = 10; while (i > 0) i++; — змінна i росте в нескінченність).
  3. Помилка точності дійсних чисел з рухомою комою (наприклад, while (x !== 1.0) { x += 0.2; } через специфіку IEEE 754 ніколи не дорівнюватиме строго 1.0).
Чим це небезпечно?
Оскільки JavaScript є однопотоковим середовищем (Single-threaded Event Loop), вічний цикл на 100% завантажує процесорне ядро, браузер повністю перестає реагувати на кліки та дії користувача, вкладка зависає («Page Unresponsive»).
Як примусово зупинити у браузері: комбінація Shift + Esc відкриває Диспетчер завдань Chrome, де можна примусово завершити процес завислої вкладки.
🛡️ Запобіжник у промисловому коді (Watchdog Counter):
Коли алгоритм складний (наприклад, обхід графу чи збірка даних), завжди додають лічильник-сторож:
let watchdog = 0; while (condition) { if (++watchdog > 10000) { console.error("Watchdog: Можливий вічний цикл! Аварійна зупинка."); break; } // тіло циклу... }

• Цикл for (параметричний)

Цикл for є найпопулярнішим у практиці розробника, оскільки компактно поєднує 3 частини в одному заголовку:

for (початок; умова; крок) { // ... тіло циклу ... }

Точний алгоритм виконання циклу JavaScript-рушієм:

  1. Початок (ініціалізація): виконується лише 1 раз при вході в цикл (let i = 0).
  2. Умова: перевіряється перед кожною ітерацією (i < 5). Якщо false — вихід.
  3. Тіло: виконується блок коду у фігурних дужках { ... }.
  4. Крок (інкремент): виконується після тіла (i++).
  5. Повтор: повернення до кроку 2 (перевірка умови).
Область видимості змінної let i:
Змінна i, оголошена за допомогою let всередині заголовка циклу, видима тільки всередині цього циклу. Більше того, рушій JavaScript створює нове лексичне оточення (нову змінну) на кожну ітерацію. Це запобігає класичним багам з асинхронністю та замиканнями (наприклад, у setTimeout).

Пропуск частин у for: будь-яку з трьох частин можна пропустити:

let i = 0; for (; i < 3;) { console.log(i++); } // for (;;) — синтаксис нескінченного циклу, повний еквівалент while(true)

• Цикл do...while (з післяумовою)

Синтаксис циклу do...while:

do { // тіло циклу (гарантовано виконається щонайменше 1 раз!) } while (умова);

Головна відмінність від while: умова перевіряється ПІСЛЯ виконання тіла циклу. Тіло гарантовано виконається хоча б один раз, навіть якщо умова з самого початку дорівнює false.

// Класичний приклад: перепитувати користувача, доки він не введе число більше 100 let num; do { num = prompt("Введіть число більше 100:", 0); } while (num !== null && num <= 100);

• Вкладені цикли (Nested Loops). Приклади використання

Вкладеним циклом називається цикл, який розташований усередині тіла іншого циклу.

Принцип роботи: на кожну ОДНУ ітерацію зовнішнього циклу внутрішній цикл виконує ВСІ свої ітерації від початку до кінця.

// Таблиця множення від 1 до 3: for (let i = 1; i <= 3; i++) { console.log(`--- Рядок ${i} ---`); for (let j = 1; j <= 3; j++) { console.log(`${i} * ${j} = ${i * j}`); } }
⏱️ Алгоритмічна складність і продуктивність:
Якщо зовнішній цикл робить $N$ ітерацій, а внутрішній $M$ ітерацій, сумарна кількість кроків дорівнює $N \times M$ (складність $O(N^2)$ для однакових розмірів). Якщо $N = 10\,000$, внутрішній код виконається 100 мільйонів разів! Тому уникайте глибокої вкладеності (3+ рівні) без явної потреби.
Блок 3 · 2 Робота з відлагоджувачем

2. Робота з відлагоджувачем (Debugger & DevTools)

• Що таке відлагоджувач. Цілі та завдання відлагоджувача

Відлагоджувач (Debugger) — це вбудований у браузер (Chrome DevTools, Firefox Developer Tools) або редактор коду (VS Code) професійний програмний комплекс, який дозволяє досліджувати внутрішній стан працюючої програми в будь-яку мілісекунду.

Чому професіонали використовують Debugger замість console.log?

  • Зупинка часу: Debugger «заморожує» виконання JS на потрібному рядку коду. Сторінка зупиняється у поточному стані.
  • Повний зріз памʼяті: ви бачите абсолютно всі змінні програми, їхні типи та обʼєкти без необхідності заздалегідь писати 20 викликів console.log.
  • Редагування значень на льоту: можна прямо в інтерфейсі відлагоджувача змінити значення змінної і подивитися, як код поведеться далі.
  • Відстеження ланцюжка викликів: видно, яка функція викликала поточну функцію (Call Stack).

• Встановлення точки зупинки (Breakpoint)

Точка зупинки (Breakpoint) — це спеціальна мітка на конкретному рядку вихідного коду, яка вказує рушію JavaScript: «Зупинись прямо перед виконанням цього рядка!».

Способи встановлення:

  1. Клік по номеру рядка у DevTools: відкрийте вкладку Sources (F12 або Cmd+Option+I у Chrome), знайдіть файл зі скриптом і клікніть мишкою по номеру рядка. Зʼявиться синій прапорець.
  2. Ключове слово debugger; у коді: спеціальна інструкція мови. Якщо інструменти розробника відкриті, браузер автоматично зупинить програму на цьому слові.
  3. Умовні точки зупинки (Conditional Breakpoint): правий клік по номеру рядка → Add conditional breakpoint... → введіть вираз (наприклад, i === 50). Зупинка відбудеться лише тоді, коли умова істинна! Це незамінно під час аналізу циклів на тисячі ітерацій.
(Перед натисканням відкрийте Chrome DevTools через F12!)

• Запуск програми за кроками та виконання одного кроку

Коли програма зупинилася на точці зупинки, у верхньому правому куті панелі Sources стають активними кнопки покрокового проходження алгоритму:

Дія Гаряча клавіша Іконка Опис поведінки
Resume F8 ▶ (Play) Продовжити звичайне швидке виконання програми до наступної точки зупинки.
Step over F10 ↷ (Next line) Виконати один наступний рядок коду в поточному контексті. Якщо на цьому рядку викликається інша функція, вона виконається цілком без заглиблення всередину її коду.
Step into F11 ⇲ (In) Увійти всередину функції, яка викликається на поточному рядку, щоб покроково відлагодити її внутрішній код.
Step out Shift+F11 ⇱ (Out) Швидко добігти до кінця поточної функції і зупинитися на рядку, звідки вона була викликана (в батьківському коді).

• Вікна для роботи з відлагоджувачем. Вікна змінних, локальних змінних, памʼяті

Під час паузи на точці зупинки бічна панель DevTools відкриває 4 ключові робочі вікна:

📦 1. Вікно областей видимості (Scope)

Показує всі доступні на даному кроці змінні, розбиті за рівнями:
• Block: змінні поточного блоку фігурних дужок (наприклад, лічильник циклу let i).
• Local: змінні поточної функції та її аргументи.
• Closure: змінні батьківських функцій, захоплені замиканням.
• Global: глобальні властивості об'єкта window.
💡 Фішка: двічі клікніть на будь-яке число чи рядок у списку Scope і введіть нове значення — воно миттєво підставиться у виконання!

👁️ 2. Вікно спостереження (Watch)

Дозволяє ввести будь-який користувацький вираз (натиснувши +):
• i * 2
• arr.length
• typeof data === "object"
На кожному натисканні F10 цей вираз буде автоматично перераховуватись і показувати свіже значення!

📚 3. Стек викликів (Call Stack)

Показує повну хронологічну ієрархію викликів функцій від початкової точки (наприклад, клік по кнопці onClick) до поточної вкладеної функції. Ви можете клікнути на будь-який попередній фрейм стеку і побачити змінні, які були в тій функції в момент виклику.

📍 4. Панель точок зупинки (Breakpoints)

Централізований список усіх створених точок зупинки в усіх файлах проекту. Дозволяє тимчасово вимкнути або увімкнути їх усі одним кліком прапорця, не видаляючи з коду. Також містить опцію «Pause on caught/uncaught exceptions» (зупинятися автоматично при виникненні будь-якої помилки).
